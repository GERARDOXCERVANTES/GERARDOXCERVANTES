## Sobre mí

Estudiante de Ingeniería en Sistemas Computacionales Cuento con experiencia práctica aplicando tecnologías modernas como Express, autenticación JWT y arquitectura de servicio. Mi perfil se complementa con el manejo de bases de datos SQL como PostgreSQL y MySQL, bases de datos NoSQL como MongoDB y herramientos esenciales como Git. Ademas, poseo conocimientos en frontend con TypeScript y un sólido manejo de Linux para entornos de desarrollo y despliegue.
